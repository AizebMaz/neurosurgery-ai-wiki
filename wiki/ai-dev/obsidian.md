# Obsidian

The recommended tool for viewing and managing an LLM wiki. Obsidian serves as the central canvas and interface for the personal knowledge base ([[video-7huCP6RkcY4-notes|source]] at 0:53).

## Roles in the System

### Data Organization — (3:06-3:47)

Provides structure for:
- **`raw/` folder** — Incoming source material
- **`wiki/` folder** — Processed, interconnected knowledge

The markdown-based format ensures compatibility with the LLM processing pipeline.

### Visualizing Knowledge — (4:06-4:18)

**Graph View**: Shows how different pieces of information, concepts, and markdown documents link together.

Benefits:
- See clusters of related ideas
- Identify orphans (unconnected pages)
- Spot hub pages (highly connected)
- Understand knowledge topology

### The 'Home' for Your Second Brain — (11:15-11:21)

The primary environment where you:
- View your memories
- Interact with the compiled wiki
- Navigate through linked concepts
- Maintain your second brain

## Why Obsidian Fits

| Feature | Benefit for LLM Wiki |
|---------|---------------------|
| Markdown native | LLM can read/write directly |
| Wiki links `[[...]]` | Cross-reference standard |
| Graph view | Visual verification of structure |
| Local files | Privacy, speed, version control |
| Plugins | Extensible for custom workflows |

## Recommended Setup

1. Open vault at your wiki root
2. Enable wiki link support
3. Use graph view to verify structure
4. Edit pages directly or through LLM

## Alternatives

While Obsidian is recommended, other markdown editors work:
- VS Code with markdown extensions
- Any text editor
- GitHub/GitLab for web viewing

But Obsidian's graph view is uniquely valuable for understanding wiki structure.
